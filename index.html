SMD Component Finder

Search SMD markings, part numbers and OCR captures — then confirm the answer against your own datasheet PDFs. Marking search is fuzzy and offline; datasheet search runs over a local RAG index of your PDF library.

InputMarking, part number, OCR or question
Best ForFast package identification and rating checks
OutputRanked candidates + datasheet evidence
WorkflowIdentify → filter → compare → verify
  1. Enter a top mark, part number or OCR result.
  2. Narrow candidates by package family.
  3. Compare confidence, package, manufacturer and datasheet evidence.
  4. Verify pinout and ratings in the datasheet before replacing.

Laser marking on black epoxy is light text on a dark background — the engine tries inverted binarisation automatically. Side lighting and sharpness matter far more than resolution.
How to get a readable frame
  • Light the body from the side: a flash straight into the lens kills contrast.
  • Move in to 3–8 cm and use macro mode or digital zoom.
  • Crop so the marking fills at least 60 % of the box width.
  • If the code stays unreadable, type it in — 2–3 characters are often enough.

2 · Search your datasheets (RAG)

Ask a question in plain words and get the passage from your own PDF library — with the part number, section and page it came from. Retrieval is BM25 over a local SQLite index; dense vectors are added automatically if an embedding backend is configured.

Serve the app with the bundled server (it exposes both the site and the API on one origin) and build the index once:

python3 tools/rag/pipeline.py --corpus data/datasheets --rebuild
python3 tools/rag/serve.py --port 8000

No PDFs yet? Generate a demo corpus: python3 tools/rag/sample_datasheets.py

3 · Marking database

CSV columns: part,mfr,pkg,type,desc,v,i,pins,markings,conf,note (markings separated by “|”, conf is high/med/low). Imported rows are stored in your browser's localStorage and never leave the device.

Privacy note: marking search, OCR and the datasheet index all run locally. Nothing is uploaded; query history and imported rows stay in your browser's localStorage.

The bundled marking database is a seed set, not an authoritative source. Always confirm against the manufacturer datasheet before replacing a component.
